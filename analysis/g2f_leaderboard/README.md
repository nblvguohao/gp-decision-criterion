# G2F 2022 leaderboard analyses

Scripts in `code/` and their outputs in `results/` for the maize competition part of the
paper: the invariance and order tests of the 22 official metrics, the pairwise reversal
rates between metrics, the rank intervals, the model-class permutation test, the paired
rank invariance of the five verified submissions, ties, and the selection-rule
sensitivity. `run_all.sh` at the repository root runs them in order (stage 1), and the
repository README maps each result in the paper to its script and output. Data
provenance and licences are in `DATA_SOURCES.md` at the repository root.
